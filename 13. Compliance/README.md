# 13. Compliance

**Supports:** Clause 9.1 (monitoring compliance), and cross-mapping to related frameworks many organizations must satisfy alongside ISO 27001.

| Subfolder/File | Purpose |
|---|---|
| GDPR | EU data protection compliance references and mapping to relevant controls (A.5.34 privacy) |
| NIST CSF | Cross-mapping between ISO 27001 Annex A and NIST Cybersecurity Framework functions |
| CIS Controls | Mapping to CIS Critical Security Controls |
| SOC 2 | Trust Services Criteria overlap with Annex A controls (useful if pursuing both) |
| Local Regulations | Jurisdiction-specific requirements (add your own — this varies by country) |

Many controls satisfy multiple frameworks simultaneously; a cross-mapping matrix avoids duplicated implementation effort.
