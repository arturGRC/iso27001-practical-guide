# Interested Parties — Hearthside Home Health

**Supports:** Clause 4.2

| Interested Party | Requirement/Expectation | How Addressed |
|---|---|---|
| Patients & families | PHI kept confidential; care not disrupted by security incidents | PHI Data Classification Policy, Incident Response Policy with patient notification procedure |
| HHS Office for Civil Rights (OCR) | HIPAA Security Rule compliance; breach reporting within 60 days | Incident Management Procedure includes OCR notification trigger; annual HIPAA risk analysis |
| Payers (Medicare/Medicaid, commercial insurers) | Evidence of administrative, physical, and technical safeguards | SoA, Internal Audit Reports made available to payer security reviews |
| Referring hospitals/physician groups | Secure data exchange (HL7/FHIR interfaces) | Vendor Security Policy applied to interface partners; encrypted data exchange |
| Mobile clinicians (180 field staff) | Usable security that doesn't slow down patient care | Mobile Device & BYOD Policy designed around real field workflows, not office defaults |
| RPM device vendors | Secure integration of device data into EHR | Vendor risk assessment on device manufacturers; network segmentation for device gateways |
| State licensing board | Operational compliance tied to license renewal | Compliance folder tracks state-specific home health security requirements |
| Cyber liability insurer | Minimum control baseline (MFA, EDR, backups) as condition of coverage | Access Control Policy (MFA), Backup Policy meet insurer requirements |
