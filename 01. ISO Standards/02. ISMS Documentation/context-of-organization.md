# Context of the Organization

**Supports:** Clause 4.1

## External Issues
- Regulatory environment (e.g., GDPR, sector-specific regulation)
- Threat landscape relevant to industry
- Market/competitive pressures related to security posture (customer security requirements)
- Technology trends (cloud adoption, AI usage) affecting risk exposure

## Internal Issues
- Organizational structure and governance
- Available resources (budget, headcount, skills)
- Existing IT infrastructure and technical debt
- Organizational culture toward security

This analysis feeds directly into Scope Document and Risk Assessment.
