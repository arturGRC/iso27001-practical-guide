# 02. ISMS Documentation

The foundational documents that define your Information Security Management System (ISMS) — required by **Clauses 4-7** of ISO 27001:2022.

| Document | Clause | Purpose |
|---|---|---|
| ISMS Manual | 4-10 (overview) | Top-level document describing how your ISMS is structured and operates |
| Information Security Policy | 5.2 | Top management's commitment to information security (mandatory document) |
| Scope Document | 4.3 | Defines ISMS boundaries — what's in/out of certification scope |
| ISMS Objectives | 6.2 | Measurable security objectives and how they're tracked |
| Context of Organization | 4.1 | Internal/external issues affecting the ISMS |
| Interested Parties | 4.2 | Stakeholders and their security requirements (customers, regulators, employees) |
| Document Control Procedure | 7.5 | How ISMS documents are created, reviewed, approved, and versioned |

**Sequencing tip:** Context of Organization and Interested Parties should be done *first* — they determine your Scope, which determines everything downstream (risk assessment, applicable controls, policies).
