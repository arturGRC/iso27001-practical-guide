# Document Control Procedure

**Supports:** Clause 7.5 (Documented Information)

## 1. Purpose
Defines how ISMS documents are created, reviewed, approved, versioned, distributed, and retired.

## 2. Procedure
1. **Creation** — Document drafted using approved template with document control header
2. **Review** — Reviewed by subject matter expert and ISMS Manager
3. **Approval** — Approved by designated owner (see per-document Document Control table)
4. **Version Control** — Version number incremented (Major.Minor); change history maintained
5. **Distribution** — Published to central repository; obsolete versions archived, not deleted
6. **Periodic Review** — Reviewed at least annually or upon significant change
7. **Retirement** — Superseded documents marked obsolete and retained per retention schedule

## 3. Naming Convention
`[category]-[document-name]-v[version].md` e.g., `policy-access-control-v1.2.md`

## 4. Retention
ISMS records retained for [X years] per legal/contractual requirements, then securely disposed of.
