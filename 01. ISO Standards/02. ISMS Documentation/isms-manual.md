# ISMS Manual

**Supports:** Clauses 4-10 (overview document)

## 1. Introduction
This manual describes how [Organization]'s Information Security Management System is structured, governed, and operated in conformance with ISO/IEC 27001:2022.

## 2. ISMS Structure (PDCA)
| Phase | Clauses | Key Outputs |
|---|---|---|
| Plan | 4-6 | Context, Scope, Risk Assessment, SoA, Objectives |
| Do | 7-8 | Resourcing, competence, operational controls, policies/procedures |
| Check | 9 | Internal audit, management review, monitoring |
| Act | 10 | Nonconformity management, corrective action, continual improvement |

## 3. Governance
- ISMS owned by [CISO/ISMS Manager], reporting to [Top Management]
- Management Review held [quarterly/biannually]
- Internal Audit Program per `10. Internal Audit`

## 4. Document Hierarchy
Policy → Procedure → Work Instruction/Template → Record, per Document Control Procedure.
