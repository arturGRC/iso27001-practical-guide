# 09. Awareness

**Supports:** Clause 7.3 (Awareness), Control A.6.3 (Information security awareness, education and training)

Security is a people problem as much as a technical one — this folder covers the human layer of the ISMS.

| Subfolder | Contents |
|---|---|
| Training Slides | Onboarding and annual refresher training decks |
| Posters | Physical/digital reminders (phishing, clean desk, password hygiene) |
| Phishing Awareness | Simulated phishing campaign materials and results tracking |
| Security Tips | Bite-sized ongoing awareness content (newsletters, Slack tips) |
| Employee Acknowledgement | Signed forms confirming policy read/understood |
