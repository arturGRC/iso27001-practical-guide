# Password Policy

**Supports:** Control A.8.5 (Secure Authentication)

| Document Control | |
|---|---|
| Document Owner | [IT Security Manager] |
| Version | 1.0 |
| Review Cycle | Annual |

## 1. Purpose
To ensure passwords and authentication mechanisms adequately protect access to systems and data.

## 2. Requirements
- Minimum 12 characters, or minimum permitted by MFA-backed system where applicable
- No password reuse across the last 10 passwords
- MFA required for all remote, privileged, and cloud administrative access
- Passwords must not be shared, written down, or stored in plaintext
- Default/vendor passwords must be changed before system go-live
- Password managers are approved and encouraged for credential storage
- Accounts lock after [5] failed login attempts

## 3. Exceptions
Any exception must be approved by [CISO] and documented with compensating controls.

## 4. Review
Reviewed annually or upon change in authentication technology (e.g., passkey adoption).
