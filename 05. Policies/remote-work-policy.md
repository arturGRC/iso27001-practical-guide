# Remote Work Policy

**Supports:** Control A.6.7 (Remote Working), A.8.1

| Document Control | |
|---|---|
| Document Owner | [IT Security Manager] |
| Version | 1.0 |
| Review Cycle | Annual |

## 1. Purpose
To ensure information security is maintained when employees work outside company premises.

## 2. Requirements
- Company devices only, unless BYOD is explicitly approved with MDM enrollment
- VPN or Zero Trust access required for all connections to internal systems
- Public Wi-Fi use requires VPN; unsecured networks must not be used for sensitive data
- Screens must be locked and privacy screens used in public spaces
- Physical documents containing sensitive data must not leave secure premises unless authorized
- Home network security baseline (WPA2/3, updated router firmware) is the employee's responsibility

## 3. Incident Reporting
Lost/stolen devices must be reported immediately per the Incident Response Policy.
