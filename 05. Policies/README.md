# 05. Policies

Nine ready-to-use policy templates covering the most commonly required ISO 27001:2022 policies. Each follows a consistent structure: Document Control → Purpose → Scope → Policy Statement → Roles & Responsibilities → Review Cycle.

| File | Control(s) Supported |
|---|---|
| `information-security-policy.md` | Clause 5.2, A.5.1 — the top-level mandatory policy |
| `access-control-policy.md` | A.5.15-A.5.18, A.8.2, A.8.3 |
| `password-policy.md` | A.8.5 |
| `remote-work-policy.md` | A.6.7 |
| `asset-management-policy.md` | A.5.9-A.5.11, A.7.9, A.8.1 |
| `acceptable-use-policy.md` | A.5.10, A.6.2 |
| `backup-policy.md` | A.8.13 |
| `incident-response-policy.md` | A.5.24-A.5.27, A.6.8 |
| `vendor-security-policy.md` | A.5.19-A.5.22 |
| `data-classification-policy.md` | A.5.12, A.5.13 |

**All bracketed `[fields]` must be customized before use** — these are starting points, not finished policies.
