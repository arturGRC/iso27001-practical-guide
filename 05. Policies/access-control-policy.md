# Access Control Policy

**Supports:** Controls A.5.15, A.5.16, A.5.17, A.5.18, A.8.2, A.8.3

| Document Control | |
|---|---|
| Document Owner | [IT Security Manager] |
| Approved By | [CISO] |
| Version | 1.0 |
| Review Cycle | Annual |

## 1. Purpose
To restrict access to information and systems based on business need, following the principle of least privilege.

## 2. Scope
All systems, applications, and data within the ISMS scope.

## 3. Policy Statement
- Access is granted on a least-privilege, need-to-know basis
- All access requests require approval from the relevant data/system owner
- Access rights are reviewed at least quarterly
- Privileged (admin) access is granted separately from standard user access and logged
- Access is revoked immediately upon role change or termination (see User Access Management Procedure, `06. Procedures`)
- Multi-factor authentication (MFA) is required for all remote and privileged access

## 4. Roles and Responsibilities
| Role | Responsibility |
|---|---|
| System/Data Owner | Approve access requests, review access rights |
| IT | Provision/deprovision access, maintain access logs |
| Employee | Use access only for authorized business purposes |

## 5. Review
Reviewed annually and after any significant access-related incident.
