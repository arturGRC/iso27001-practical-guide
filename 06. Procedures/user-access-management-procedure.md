# User Access Management Procedure

**Supports:** Access Control Policy | Controls A.5.16, A.5.18, A.8.2, A.8.5

## 1. Purpose
Defines the step-by-step process for granting, modifying, reviewing, and revoking user access.

## 2. Procedure
### 2.1 Onboarding (New Access)
1. HR initiates access request via [ticketing system] on employee start date
2. System/data owner approves access scope based on role
3. IT provisions accounts with least-privilege defaults; MFA enrolled before first login
4. Access grant logged with requester, approver, date, and scope

### 2.2 Role Change
1. Manager submits access change request
2. Old access revoked, new access granted per new role — no accumulation of unused rights
3. Change logged

### 2.3 Offboarding (Termination)
1. HR notifies IT on/before last working day (same-day for involuntary termination)
2. All access revoked within [4 hours] of notification
3. Company assets returned and logged
4. Offboarding checklist completed and filed in `08. Records`

### 2.4 Periodic Access Review
1. Quarterly, system owners review active access lists against current roles
2. Discrepancies remediated within [5 business days]
3. Review evidence retained in `08. Records`

## 3. Records
Access grants, changes, and reviews are logged and retained for [X years] per Document Control Procedure.
