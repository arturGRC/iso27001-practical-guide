# 07. Templates

Reusable, blank forms referenced throughout the toolkit — the "paperwork" of running an ISMS.

| File | Used for |
|---|---|
| `statement-of-applicability-template.csv` | The single most important audit artifact — documents which of the 93 Annex A controls apply and why |
| `internal-audit-checklist-template.csv` | Running internal audits (`10. Internal Audit`) |
| `risk-assessment-template.csv` | Risk Management (`03. Risk Management`) |
| `corrective-action-report-template.md` | Closing nonconformities (Clause 10.1) |
| `management-review-minutes-template.md` | Clause 9.3 management reviews |
| `security-incident-form-template.md` | First response to any incident |
| `asset-inventory-template.csv` | Asset Register |
| `internal-audit-plan-template.md` | Annual audit scheduling |
